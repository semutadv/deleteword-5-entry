The word I would delete from the dictionary, nominated for the
make.fun bounty of that name: literally. It is the only word that now
means its own opposite, so nobody can tell whether it is being used
or abused. Deleting it would be the word's first honest moment in
decades.

## Running it

`node main.ts` clears the output directory's contents and writes the
word to `/output/entry.txt` as plain UTF-8 text.
